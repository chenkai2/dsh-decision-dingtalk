# 等你决策 · 钉钉

把任何一个 DSH 会话正在等你拍板的东西——工具审批、待审计划、`ask_user_question` 提问——推到钉钉，并允许你在钉钉里直接答复。

## 它解决什么

跑长任务时，会话停下来等你批准，而你人在别的窗口或别的房间。工作台的黄点只有你回头看才看得见；这个插件在你还没回来之前，就把那张卡发到钉钉。

打开钉钉回一句 `#a7k2 批准`，会话继续跑；不想在手机上处理也行，回工作台点卡片一样生效——两侧同时有效，先答的那次算数。

## 前提

- 群机器人（`push.mode: dws`）需要机器人已经在目标群里，并且你有它的 robot code；
- 回复回收（`read.mode: dws`）走本机 `dws`，以**你本人**的钉钉身份读消息，所以要先 `dws auth login`。

只想被提醒、不需要在钉钉裁决时，把 `behavior.answerInChat` 关掉：插件不再轮询回复，工作台仍是唯一的裁决入口。

## 和同类插件的分工

- 只想要系统通知 / 提示音 / 标签页标记：`dsh-notify-me`、`dsh-pharos` 更合适，它们不碰 IM。
- 想把「一个聊天 ⇄ 一个会话」整条接进钉钉来驱动：那是 `dsh-connect` 的思路，它由聊天驱动会话。
- 本插件只看**已经在跑的会话**在等你什么，不改会话的驱动方式。

## 安全

- 读到机器人自己发的消息、以及工具通过你账号发出的消息（带 `messageAiSendFlag`）一律不当答复，避免自激。
- `read.allowSenders` 建议填上你自己的 userId；留空表示目标会话里任何真人都能答。
- 凭据只存在 profile 的 `cordis.patch.yml`（本机），插件不写任何文件、不发任何遥测。

## 已知限制

- 在钉钉裁决后，网页上那张卡不会立刻消失，点它会提示已失效——卡片状态由工作台维护。
- 卡片发出后如果 `dws` 掉线或机器人被踢出群，回复收不到；日志里会有 warn，请求仍留在工作台等你。
- 不支持把钉钉的互动卡片按钮带上来（群自定义机器人与 `dws` 都只发 Markdown），裁决靠回文字。
